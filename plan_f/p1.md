## 2. HTTP client and error model

`src/infrastructure/http/httpClient.js`

- Keep the request interceptor that adds `Authorization: Bearer <token>`, but read the token through an injected
  getter so the session logic lives in one place (Phase 2 plugs it in): `configureHttp({ getToken, onUnauthorized })`.
- Response interceptor converts every failure into an `ApiError` (new file `src/infrastructure/http/apiError.js`):

```js
// { status, message, fieldErrors }  status 0 = network/timeout
// FastAPI: { detail: "text" }               -> message = detail
//          { detail: [{ loc, msg, type }] } -> fieldErrors = { [loc.at(-1)]: msg }, message = first msg
```

- On `401` call `onUnauthorized()` (set in Phase 2) — the client itself no longer touches storage.
- Export `ApiError` so stores can test `e.status === 404` without importing Axios.

Tests: `tests/unit/apiError.test.js` — string detail, 422 array detail, network error, unknown body.

## 4. API adapters return models

Each file in `src/infrastructure/api/` calls `httpClient`, then the mapper, and returns the model. Also add the
missing params the backend supports so later phases don't have to touch adapters again:

| Adapter | Functions (backend endpoint) |
|---|---|
| `authApi` | `register(body)` → `POST /auth/register` → `toUser`; `login({identifier,password})` → `POST /auth/login` → `{ accessToken }`; `logout()` → `POST /auth/logout` |
| `drugsApi` | `search(query, limit)` → `GET /drugs`; `overview(rxcui, { dosageForm, route })` → `GET /drugs/{rxcui}/overview?dosage_form&route`; `reactionTrend(rxcui, months)`; `labelGaps(rxcui, minReports)` (unwrap envelope) |
| `shortagesApi` (new, split from drugsApi) | `alternatives(rxcui, { dosageForm, route })` → `GET /shortages/{rxcui}/alternatives` |
| `signalsApi` | `list({ quarter, rxcui, reaction, minReports, onlySignals, page, pageSize })`; `emerging({ quarter, minReports, page, pageSize })`; `reports(rxcui, reaction, { page, pageSize })` with `encodeURIComponent(reaction)` |
| `statisticsApi` | `get({ groupBy, rxcui, quarter })` |
| `cabinetApi` | `list`, `follow(rxcui)`, `unfollow(rxcui)`, `alerts`, `dismiss(id)`, `dismissAll` |
| `profileApi` | `get`, `update({ username, email })`, `changePassword({ currentPassword, newPassword })`, `remove`, `getAlertSettings`, `saveAlertSettings(model)` |

camelCase → snake_case conversion for query params and bodies happens inside the adapter (small `toQuery()` helper
that also drops `null`/`undefined`/`''` so optional filters are not sent as empty strings).
