# Phase 5 — Signals and statistics (View 4: FR-04 to FR-09)

**Goal:** the signal explorer: filter by drug, reaction, quarter and minimum reports; paginated table with PRR,
CI lower bound, chi-square, label status and trend; tabs for all / emerging / label gaps; the individual reports
behind a signal; and statistics charts on real data.

**Fixes:** M12 (UI), M14, M15. **Backend endpoints:** `GET /signals`, `GET /signals/emerging`,
`GET /signals/{rxcui}/{reaction}/reports`, `GET /statistics?group_by=`, `GET /drugs/{rxcui}/label-gaps`.

---

## 1. Backend facts

- `GET /signals?quarter&rxcui&reaction&min_reports=20&only_signals=true&page&page_size` → envelope with
  `SignalList { items, total, page, page_size, total_pages, quarter, match_coverage }`. `quarter` omitted = latest.
  `rxcui` filters by ingredient (not drug name), `reaction` is normalised server-side (case-insensitive).
- `only_signals=false` also returns pairs that don't meet the Evans criteria (PRR >= 2, chi² >= 4, a >= 3) — use it for a
  "show all pairs" toggle, off by default.
- `GET /signals/emerging` — same envelope, default `min_reports=3`.
- `GET /drugs/{rxcui}/label-gaps?min_reports=20` → envelope with `LabelGapsData` — **per drug**, so the Label gaps tab
  needs a drug selected.
- `GET /signals/{rxcui}/{reaction}/reports?page&page_size` → `SignalReports` (no envelope). Reactions with `/` break
  this route (request B2).
- `GET /statistics?group_by=age_group|sex|country|seriousness|report_type|quarter&rxcui&quarter` → `{ group_by, buckets }`.
  `group_by` is required.

## 2. URL is the source of truth for filters

Filters and tab live in the query string so links from the dashboard and browser back/forward work:
`/signals?tab=all|emerging|gaps&rxcui=&reaction=&quarter=&min=20&page=1`.
The store reads them on enter (`route.query` → `filters`) and "Apply filters" writes them (`router.replace`).
Mapping between query and filters is a pure function `filtersFromQuery` / `queryFromFilters` with tests.

## 3. Tasks

### 3.1 `useSignalStore`
- State: `filters { tab, rxcui, drugName, reaction, quarter, minReports, onlySignals, page, pageSize }`,
  `list` (page model), `usedQuarter`, `matchCoverage`, `disclaimer`, `quarters`, `labelGaps`, `stats { age, sex, seriousOverTime }`,
  `reportsDrawer { open, rxcui, reaction, page, items, total }`, per-section loading/error.
- `loadQuarters()` — B3 fallback: `statistics({ groupBy: 'quarter' })` → sorted bucket names, newest first.
- `loadTable()` — by tab: `all` → `signals.list`, `emerging` → `signals.emerging`, `gaps` → `drug.getLabelGaps`
  (requires `rxcui`; otherwise show "Choose a drug to see its label gaps").
- `loadStats()` — in parallel: `age_group`, `sex`, and serious-over-time (B4 fallback: `group_by=quarter` for the
  "All reports" line and `group_by=seriousness&quarter=Q` for each of the last 6 quarters for the "Serious" line,
  run with `allSettled`). Stats use the same `rxcui`/`quarter` filters as the table, so the charts describe what
  the table shows.
- `openReports(row)`, `loadReportsPage(n)`, `closeReports()`.
- Request de-duplication: ignore stale responses when filters change quickly (same counter pattern as search).
